### Code

**최종 debounce (BFE #5 통과)**

```javascript
function debounce(func, wait) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      func(...args);
    }, wait);
  };
}
```

> 이게 면접 표준 답안. wrapper HOF + closure (timer) + `...args` forwarding 3박자.

**bonus — throttle (Q1 변형 질문 도출)**

```javascript
function throttle(func, wait) {
  let timer = null;
  return function (...args) {
    if (timer !== null) return;
    timer = setTimeout(() => {
      func(...args);
      timer = null;
    }, wait);
  };
}
```

> debounce 와의 핵심 차이는 단 두 줄:
> - debounce: `clearTimeout(timer)` 매번 → "마지막 호출 후 N ms 조용하면 실행"
> - throttle: `if (timer !== null) return` → "N ms 동안 최대 1회"
