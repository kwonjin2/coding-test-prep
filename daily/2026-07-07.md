- **Problem**: LeetCode 167, Two Sum II - Input Array Is Sorted, Medium
- **Tags**: 투포인터, 배열
- **Time**: 미기록
- **Status**: 🟡
- **Stuck at**: 브루트포스(이중 for문)로 먼저 접근. "정렬됨"이라는 조건을 언급은 했으나 코드에 반영 안 함 → 안 쓰인 단서 짚어준 뒤 좌우 포인터 이동 방향은 자력으로 도출
- **Key learning**: 정렬된 배열 + 투 포인터로 O(n²) → O(n), O(1) 개선. sum 비교 3분기는 상호 배타적이므로 `else if`로 정리
- **Retry**: 2026-07-14

### Code

```javascript
/**
 * @param {number[]} numbers
 * @param {number} target
 * @return {number[]}
 */
var twoSum = function (numbers, target) {
  let left = 0;
  let right = numbers.length - 1;

  while (left <= right) {
    if (numbers[left] + numbers[right] === target) return [left + 1, right + 1];
    else if (numbers[left] + numbers[right] < target) left++;
    else right--;
  }
};
```

### 시간/공간 복잡도

- Time: O(n)
- Space: O(1)
