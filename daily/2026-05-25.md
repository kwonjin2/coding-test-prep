### Code

**Map 풀이 (자력)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;

  const map = new Map();

  for (let i = 0; i < s.length; i++) {
    map.set(s[i], (map.get(s[i]) ?? 0) + 1);
  }

  for (let i = 0; i < t.length; i++) {
    map.set(t[i], (map.get(t[i]) ?? 0) - 1);
  }

  for (const [, count] of map) {
    if (count !== 0) return false;
  }

  return true;
};
```

> 길이 early exit 자발적으로 넣음. `??` 로 첫 등장 처리. **Map 한 개로 +/-** 처리 (두 Map 비교보다 한 단계 위).

**배열 26 풀이 (힌트 사다리 받고 작성)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;

  const count = new Array(26).fill(0);

  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - 97]++;
  }
  for (let i = 0; i < t.length; i++) {
    count[t.charCodeAt(i) - 97]--;
  }

  for (const c of count) {
    if (c !== 0) return false;
  }
  return true;
};
```

> 디버깅 포인트 2개:
> 1. `s.charCodeAt[i]` (인덱싱) → `s.charCodeAt(i)` (메서드 호출). 전자는 `undefined`.
> 2. `- 97` (`'a'.charCodeAt(0)`) 빠지면 인덱스 97~122 → 길이 26 배열 밖. JS 는 에러 안 나고 NaN 으로 조용히 깨짐.

**정렬 풀이 (방향만 자력 — 한 줄 비교까진 못 떠올림)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;
  return s.split('').sort().join('') === t.split('').sort().join('');
};
```

### 시간/공간 복잡도

| 풀이 | Time | Space |
| ---- | ---- | ----- |
| Map | O(n) | O(n) (또는 O(min(n, 26))) |
| **배열 26** | O(n) | **O(1)** |
| 정렬 | O(n log n) | O(n) |

> 면접 trade-off 답변: "기본은 배열 26 (제약 활용). 글자 도메인 제한 없으면 Map. 코드 짧음 우선이면 정렬."

### Interviewer feedback (Claude)

- ✅ **5/22 Two Sum 의 진짜 시험대 통과** — "lookup → Map 자력 소환" 됨. 빈도수 카운팅이라는 Map 의 두 번째 변형도 같은 호흡으로 떠올림.
- ✅ 길이 early exit, `??` 로 분기 압축, **Map 한 개로 +/-** 처리 — 디테일이 한 단계 위. 면접관 가산점.
- ⚠️ **"더 빠르게/메모리 적게" 후속을 또 자력으로 못 던짐** (5/22 미해결 항목과 동일). 제약 ("영소문자만") 을 공간 분석에 직접 연결시키는 회로가 아직 약함. 다음 번엔 풀이 직후 **"제약을 한 번 더 읽고, 자료구조의 동적 크기 필요한가" 자문** 루틴화.
- ⚠️ `s.charCodeAt(i)` 는 면접에서 흔한 syntax slip. 다음 번엔 콘솔 한 번 안 찍어도 한 번에 쓰게 굳히기.
- 📝 정렬 풀이 방향 ("정렬해서 같은지") 자력으로 떠올린 건 좋음. JS 한 줄 비교 (`split.sort.join`) 패턴은 다음 anagram 류 (Group Anagrams 등) 에서 자연스럽게 재등장 — 그때 또 보자.
