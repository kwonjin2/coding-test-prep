- **Key learning**: Anagram = **multiset 동일성** 문제. 같은 문제를 푸는 **자료구조 결정 트리**가 input constraint 에 종속:
  - 영어 소문자만 → **배열 26 (공간 O(1) 확정 이득)**
  - 일반 (유니코드 등) → Map/Object 카운팅
  - 가독성 우선 / 자료구조 안 쓰고 싶으면 → 정렬 (대신 O(n log n))
  이 결정 트리 자체를 면접에서 한 호흡에 펼쳐낼 수 있어야 가산점. 그리고 본인이 답할 때 **"input 가정 한 줄 → 그 가정 하의 복잡도 한 줄"** 을 묶어서 답하는 회로 필요 (이번엔 분리되어 불일치 발생).

### Code

**자력 풀이 (~7분, 통과)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;

  const map = new Map();

  for (let i = 0; i < s.length; i++) {
    map.set(s[i], (map.get(s[i]) || 0) + 1);
  }

  for (let i = 0; i < s.length; i++) {
    map.set(t[i], (map.get(t[i]) || 0) - 1);
  }

  for (const m of map.values()) {
    if (m !== 0) return false;
  }

  return true;
};
```

> 길이 다르면 조기 종료 ✅. s 에서 +1, t 에서 -1, 모두 0 ⇔ anagram 패턴 ✅. `(map.get(x) || 0)` 자력 ✅. 코드 자체는 정석.

**대안 1 — 배열 26 (영어 소문자 가정, 면접 답안용)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;

  const count = new Array(26).fill(0);
  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - 97]++;
    count[t.charCodeAt(i) - 97]--;
  }
  return count.every((c) => c === 0);
};
```

> 핵심 트릭: `charCodeAt(i) - 97` 로 'a'~'z' → 0~25 인덱스 매핑. **s 의 +1 과 t 의 -1 을 같은 loop 에서** 처리 가능 (length 가 같다고 보장됐으니).

**대안 2 — 정렬 후 비교 (가독성 우선)**

```javascript
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;
  return s.split('').sort().join('') === t.split('').sort().join('');
};
```

> 코드 가장 짧음. Time **O(n log n)** — 비교 기반 정렬의 하한. 면접에서 "다른 방법?" 후속에 즉답 가능해야.

### 시간/공간 복잡도 (세 접근 비교)

| 접근                  | Time           | Space  | 가정              |
| --------------------- | -------------- | ------ | ----------------- |
| Map/Object 카운팅     | **O(n)**       | O(k)\* | 없음 (범용)       |
| 배열 26 카운팅        | **O(n)**       | **O(1)** | 영어 소문자만     |
| 정렬 후 비교          | **O(n log n)** | O(n)   | 없음              |

\* k = 고유 문자 수. 영어 소문자만이면 k ≤ 26 → 실질 O(1) 이지만, 면접에선 가정을 명시한 후에 답할 것.

**면접 정답 패턴**: "input constraint 따라 — 소문자만이면 배열 26 (공간 O(1)), 일반이면 Map. 정렬은 코드 짧지만 보통 안 고름 (시간 O(n log n))."
