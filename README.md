# Coding Test Prep

코딩테스트 / 라이브 코딩 면접 대비용 학습 로그.

## 목표

알고리즘 기본기 + 프론트엔드 라이브 코딩 + think-aloud

## 운영 구조

```
.
├── README.md     # 이 문서 (불변)
├── LOG.md        # 인덱스 + 한줄요약 + 주간요약 (매일 업데이트)
└── daily/        # 일별 상세 기록
    └── YYYY-MM-DD.md
```

## 학습 사이클

| 요일         | 활동                                                                  | 시간    |
| ------------ | --------------------------------------------------------------------- | ------- |
| 월·화·목·금  | 알고리즘 1문제 (LeetCode/프로그래머스)                                | 45~60분 |
| 수           | 프론트엔드 라이브 코테 1주제 (think-aloud, bigfrontend/gratefrontend) | 30~45분 |

주 4 알고리즘 + 주 1 프론트. **하루 빠지는 건 OK, 이틀 빠지는 건 위험 신호.**

## 기록 원칙

### 1. 매 세션 끝나고 **바로** 기록 (몰아쓰기 X)

- 기억 왜곡 막기 위함
- 5분 안에 끝낼 수 있게 필드 최소화

### 2. Status는 5단계

- 🔴 **Failed** — 시간초과 + 못 풀음
- 🟠 **Solved with solution** — 해설 봄
- 🟡 **Solved with hint** — 힌트 받음 (검색/질문)
- 🟢 **Solved cleanly** — 막힘 없이 풀음
- 🔵 **Solved + optimized** — 풀고 시간/공간 개선까지

### 3. "Stuck at"

- 어디서 막혔는지 한 줄로
- 막힌 적 없으면 `-`
- 일주일 모이면 약점 패턴이 보임

### 4. Retry 날짜 박기 (망각 곡선 대응)

- 🔴: 3일 후
- 🟠: 5일 후
- 🟡: 1주 후
